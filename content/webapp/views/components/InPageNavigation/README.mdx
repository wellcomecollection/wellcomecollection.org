## Purpose
Optionally (in Prismic) provides in-page navigation to all sections headed by H2s on any `page`.

## Usage notes

Use when:
- There are more than 3 H2s on a content page
- Content page is long and contains discrete nuggets of information; where a user might only be interested jumping to a specific part

Don't use on:
- `articles`
- `events`
- `exhibitions`


## Dark backgrounds

On desktop the nav's text is dark unless it's over an element marked `data-in-page-nav-dark`. If the nav sits over a dark band, mark the band (and, if it ends in a `WobblyEdge`, the edge's wrapper with `data-in-page-nav-dark-edge`), as the concept and sub-theme pages do.
